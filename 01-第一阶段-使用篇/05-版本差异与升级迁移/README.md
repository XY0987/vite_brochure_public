# 第一阶段 · 使用篇 / 05 版本差异（使用 / 选型视角）

> 本章对应《Vite：从使用到精通》第一阶段第 5 项「版本差异（使用 / 选型视角）」。
> 事实基线：2026 年中，Vite 8.1.x（默认唯一打包器 Rolldown 1.1.x，Oxc 接管转译/压缩；Rolldown 1.0 已于 2026.05 稳定）。

本章目标：把你从「被一堆 Vite 版本号搞晕」带到「能读懂每个版本变了什么、为什么变，并据此做升级与选型决策」。核心方法论是**两条独立演进主线**——架构抽象（Environment API，Vite 6 引入）与打包器替换（Rolldown，Vite 7 可选、Vite 8 默认）。

| 版本 | 时间 | 核心变化 |
|---|---|---|
| Vite 5 | 2023 底 | esbuild(dev) + Rollup(build) 双引擎，企业现役主力 |
| Vite 6 | 2024.11 | Environment API；多环境模型；大规模内部重构但向后兼容 |
| Vite 7 | 2025.06 | 清理废弃特性、`rolldown-vite` drop-in、Node 20.19+/22.12+ |
| Vite 8 | 2026.03 | Rolldown 成为默认唯一 Rust 打包器，dev/build 统一，构建快 10–30x，Oxc 接管转译/压缩 |

## 阅读建议

01 是地基（两条主线的心智模型），所有人必读。02 是升级时查得最多的「配置改名速查」。03 讲新能力，做长效缓存/微前端的重点看。04/05 是实战：04 解决「同工具升版本」，05 解决「换工具搬家」，按你的实际场景挑读。顺序读最佳；只升级看 01→02→04，只迁移看 01→05。
