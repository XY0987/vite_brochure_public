# 第一阶段 · 使用篇 / 06 打包工具横向对比（差异 · 关系 · 应用场景）

> 本章对应《Vite：从使用到精通》第一阶段第 6 项「打包工具横向对比（差异 · 关系 · 应用场景）」。
> 事实基线：2026 年中，Vite 8.1.x（默认唯一打包器 Rolldown 1.1.x，Oxc 接管转译/压缩；Rolldown 1.0 已于 2026.05 稳定）。

本章目标：把你从「esbuild / Rollup / Rolldown / webpack / Oxc 这几个名字老是分不清」带到「能一句话说清每个工具的定位、它们彼此什么关系、自己的项目该用哪个」。这是第一阶段「使用 → 选型」的最后一块拼图——前面五章教你把 Vite 用好，本章教你**抬头看整个打包工具生态**，知道 Vite 站在什么位置、底下踩着哪些工具。

> 注意边界：本章是**使用 / 选型视角**的横向对比——讲定位、关系、怎么选。每个工具**内部怎么实现**（Rollup vs Rolldown 的模块图、Oxc 的 AST 管线等）属于第二阶段「源码层面」的深度对比，本章只在需要时点到为止，不展开实现细节。

## 五个工具一句话定位

| 工具 | 语言 | 类型 | 一句话定位 | 在 Vite 8 中的角色 |
|---|---|---|---|---|
| esbuild | Go | 打包器 + 转译器 | 极快，但产物控制弱 | 已退场（转译交给 Oxc、打包交给 Rolldown），仅作兼容/兜底 |
| Rollup | JavaScript | 打包器 | 库/生产打包的事实标准，产物优、慢 | Vite 2–7 的 build 引擎，Vite 8 退为兼容层 |
| Rolldown | Rust | 打包器 | Rollup 的 Rust 重写，统一 dev+build | **默认唯一打包器** |
| webpack | JavaScript | 打包器 | 老牌全能、生态最厚、配置最重、冷启动慢 | 不在 Vite 内，是 Vite 在「应用构建」上正取代的对象 |
| Oxc | Rust | 工具链（非打包器） | Rust 版的解析/转译/压缩/Lint 工具集 | **接管转译（TS/JSX）与压缩** |

## 配套代码

所有可运行 demo 位于配套 GitHub 仓库 [第一阶段-使用篇/06-打包工具横向对比/](https://github.com/XY0987/vite_brochure_code_public/tree/main/第一阶段-使用篇/06-打包工具横向对比/)，按上表「配套代码」列一一对应。每个 demo 自包含、可独立 `npm install` 后运行。运行环境要求 Node ≥ 20.19 / 22.12（Vite 8 / Rolldown 硬性要求），详见代码仓库根 README。
