# 第二阶段 · 源码篇（深入实现）

> 本阶段对应《Vite：从使用到精通》第二阶段第一部分「源码层面（深入实现）」主线 12 节。
> 源码基线：**Vite 8.1.0**（`packages/vite/package.json` → `"version": "8.1.0"`），Rolldown `~1.1.2`、Oxc 工具链。事实基线时间：2026 年中。

本阶段回答一个问题：**「它内部到底怎么实现的」**。不是「读源码」，而是「调源码」——每一节都按同一节奏推进：

1. **亲手调试**：clone 最新源码、本地起服务、在关键函数打断点、跟一次真实流程；
2. **梳理实现**：把跑通的链路抽象成调用链与机制图；
3. **小结取舍**：这段实现解决了什么问题、又引入了什么复杂度。

## 配套源码仓库

本阶段所有断点、行号都基于本书配套的 Vite 源码仓库（fork 自 Vite 8.1.0，已内置断点标注与 `.vscode/launch.json`）：<https://github.com/XY0987/vite_ori_public>

```bash
git clone https://github.com/XY0987/vite_ori_public.git
cd vite_ori_public
# 该仓库的 main 分支即带断点标注的 8.1.0 基线，无需再 checkout 官方 tag
pnpm install
pnpm --filter=./packages/vite run build   # 首次需要构建一次产物
```

**约定**：正文里出现的源码路径，凡以 `packages/vite/...` 开头的，都是相对于这份 Vite 源码仓库根目录的路径；行号形如 `L150–207` 表示该函数/片段在文件中的位置（8.1.0 基线，后续版本可能漂移）。配套的 `.vscode/launch.json` 调试配置见 [01 环境准备与调试入门](01-Vite实现原理/01-环境准备与调试入门.md)。

**断点已在源码里标注好**：每个推荐断点都已在源码对应行行尾加了一条以 `🔖断点` 开头的说明注释。你不必死记行号——在编辑器里全局搜索 `🔖断点`（或按节搜 `🔖断点[小册08]`）即可定位所有断点并看到它在这一步做什么。这些注释加在行尾、不改变行号，是配套学习标注（非 Vite 原始源码，`git checkout .` 可还原）。完整的「小节 ↔ 源码入口 ↔ 断点」对照表见源码仓库的 `源码学习/README.md`。

## 阅读建议

- **先看地图**：强烈建议先通读 [00 源码全景与模块关系](01-Vite实现原理/00-源码全景与模块关系.md)——它给出整张仓库的模块关系图、「一次完整 dev 请求穿过所有模块」的端到端串联、核心模块速查表与学习路径。后面 01–12 是对这张图上每个节点的放大。
- **顺序读最稳**：00（建立全景）→ 01（搭好调试环境）→ 02、03（启动前：配置与插件就位）→ 04、05、06、07（dev 期：预构建与按需编译主干）→ 08、09、10（dev 期：HMR、模块图、多环境）→ 11、12（build 与 preview）。
- **按需跳读**：只想搞懂 HMR 全量刷新？直接看 08 + 09。只关心 Vite 8 的 Rolldown 构建差异？看 11。
- **务必动手**：每节都给了「推荐断点」。光看链路图记不住，亲手在断点处看一次变量，理解会牢固得多。
